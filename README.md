# Maestría Social — propuesta de funnel (Reflex)

Prototipo navegable de la propuesta de rediseño de funnel para Coach Social.

| Página | Qué es |
|---|---|
| `index.html` | La propuesta: diagnóstico, estrategia, plan de medición y panel de notas |
| `variante-a.html` | Landing A — ángulo "El ascenso" |
| `variante-b.html` | Landing B — ángulo "No es oratoria" + diagnóstico de estilo de carisma |
| `agendar.html` | Agenda en 3 pasos: contacto → calificación → calendario |
| `gracias.html` | Página de gracias, pensada para subir la asistencia a la llamada |
| `vsl-guion.html` | Guion del VSL (2 hooks) y del video pre-llamada |

Sitio estático, sin build. `render.yaml` crea el static site en Render.

Pendiente al implementar: grabar el VSL, embeber el calendario de GHL, número de WhatsApp,
webhook de leads, pixel de Meta y volver a subir imágenes/videos de testimonios al hosting propio.
